# Design plugin provenance

This plugin is derived from the upstream `design` plugin (`0.7.2`) shipped in
`zai-org/ZCode` under `apps/zcode-cli/packages/design-plugin`, licensed under
Apache-2.0.

NIBI modifications: plugin manifest moved to `.nibi-plugin`, plugin host
variables renamed to `NIBI_*`, product references renamed to NIBI, and the
plugin is bundled as a NIBI built-in.

The design resources under `skills/design/design-resources/` retain their own
license files (`LICENSE.md`, `LICENSE-html-ppt`, `NOTICE.md`).
